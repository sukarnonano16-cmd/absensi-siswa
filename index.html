Informasi Sistem

Versi: SIAS 1.0 • Penyimpanan: browser localStorage (offline) + Sinkron Cloud opsional via Firebase Firestore (multi perangkat, saat online). Atur di menu ☁️ Sinkron Cloud.

☁️ Sinkron Cloud (Multi Perangkat)

Hubungkan aplikasi ke database cloud gratis (Firebase Firestore) agar data siswa, kelas, dan absensi otomatis tersinkron ke semua laptop & HP yang memakai Kode Sinkronisasi yang sama, selama perangkat terhubung internet.

Status: Belum terhubung

Cara Mendapatkan Konfigurasi Firebase (Gratis, ±5 menit)

  1. Buka console.firebase.google.com, login dengan akun Google, lalu klik Add project / Tambah proyek.
  2. Setelah proyek dibuat, di halaman utama klik ikon </> (Web) untuk mendaftarkan aplikasi web, beri nama bebas, klik Register app.
  3. Salin seluruh objek firebaseConfig yang ditampilkan (dari tanda { sampai }), lalu tempel ke kotak konfigurasi di atas.
  4. Di sidebar kiri Firebase Console, buka Build → Firestore Database, klik Create database, pilih lokasi server, dan pilih mode Test mode (agar aplikasi bisa langsung membaca/menulis data).
  5. Isi kolom Kode Sinkronisasi bebas (mis. nama sekolah), lalu klik Hubungkan & Sinkron. Masukkan Firebase config dan Kode Sinkronisasi yang sama persis di setiap laptop/HP agar datanya saling terhubung.

Catatan: mode Test biasanya otomatis nonaktif (mengunci akses) setelah ~30 hari. Jika sudah lewat, buka menu Firestore Database → Rules dan ganti menjadi selalu mengizinkan baca/tulis, atau perpanjang masa Test mode.
